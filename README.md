
# AttendX-Test-Scripts

## Project Description
This repository contains sample test scripts for the
AttendX student attendance application.

## Files
- login_test.py: Checks valid and empty login fields.
- attendance_test.py: Checks valid and invalid attendance data.

## Purpose
To demonstrate version control of test scripts using
Git and GitHub.

## Tools Used
- Visual Studio Code
- Git
- GitHub
- Python
